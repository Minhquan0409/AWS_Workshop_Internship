During the First Cloud AI Journey (FCAJ) program, I had the opportunity to consolidate my knowledge of the AWS platform through learning materials, hands-on exercises, workshops, blogs, and the development of a practical project.

Throughout the learning and practice process, I became familiar with various AWS services such as IAM, EC2, VPC, S3, CloudFront, AWS WAF, CloudWatch, SNS, and Lambda. In particular, through the **SkyLink Airline** Workshop, I applied AWS services to deploy the Frontend on Amazon S3, distribute content through Amazon CloudFront, protect the system using AWS WAF, and implement monitoring and alerting mechanisms with CloudWatch and SNS.

In addition to technical knowledge, the Workshop also helped me improve my ability to independently research documentation, troubleshoot configuration issues, analyze logs, and resolve problems that arose during the deployment process on AWS.

## Development Direction & Areas for Improvement

Based on my learning process and Workshop implementation, I have identified several areas that I need to continue improving:

- **Expand AWS technical knowledge:** Continue exploring advanced AWS security and monitoring services such as AWS GuardDuty, AWS Shield, AWS Security Hub, and other Cloud security solutions.

- **Improve Infrastructure as Code skills:** Gain deeper knowledge of AWS CloudFormation and Terraform to automate infrastructure deployment and management.

- **Improve system architecture knowledge:** Continue studying the AWS Well-Architected Framework, particularly in the areas of scalability, reliability, security, and cost optimization.

- **Develop DevOps skills:** Learn more about Docker, Amazon ECS, CI/CD, and tools that support automated build and deployment processes.

- **Improve troubleshooting skills:** Continue practicing log analysis, metric monitoring, and root-cause analysis for issues occurring in Cloud environments.

- **Improve communication and presentation skills:** Practice presenting system architectures, deployment processes, and technical solutions in a concise, visual, and easy-to-understand manner.

## Conclusion

The First Cloud AI Journey (FCAJ) program gave me an opportunity to strengthen my AWS knowledge and apply what I had learned to a practical project. Through the **SkyLink Airline** Workshop, I gained a better understanding of the process of deploying a Web application on AWS, from storing files on Amazon S3 and distributing content through CloudFront to protecting the system with AWS WAF and implementing monitoring and alerting with CloudWatch and SNS.

The implementation process also helped me improve my self-learning, documentation research, troubleshooting, and technical documentation skills. These experiences provide an important foundation for me to continue developing my knowledge of AWS Cloud, DevOps, and Cloud Security in my future studies and career.
