This is a list of technical articles that I published on the AWS Study Group community during my internship:

### [Blog 1 - AMAZON EVENTBRIDGE — THE HEART OF EVENT-DRIVEN SECURITY ARCHITECTURE ON AWS](3.1-Blog1/)

Amazon EventBridge is a fully managed serverless event bus service provided by AWS that allows applications to communicate with each other through real-time events. In Security Detection & Response systems, EventBridge plays a central role in orchestrating the entire automated processing workflow.

### [Blog 2 - Building an End-to-End Machine Learning Pipeline with Amazon SageMaker](3.2-Blog2/)

In this article, I will present the process of building an End-to-End Machine Learning Pipeline with Amazon SageMaker, from data preparation and model training to evaluation and deployment. This provides a clearer understanding of how SageMaker supports the automation and management of the entire Machine Learning workflow on the AWS platform.

### [Blog 3 - Preventing Data Leakage on AWS with Egress Controls for Cloud Workloads](3.3-Blog3/)

In this article, I will explore how to prevent data leakage on AWS using Egress Controls for Cloud Workloads, focusing on controlling data flows leaving the Cloud environment. The article clarifies access control mechanisms, restrictions on unnecessary connections, and ways to enhance data security during the operation of AWS systems.
